Cinema and rooftop planetarium

The model is positioned at world (12, 0, -56.5), with a 24 x 33 m footprint facing south. The aquarium is behind it and the east tunnel remains clear. The marquee is blank pending a name. The Blender source has CinemaExterior, CinemaInterior and PlanetariumInterior collections. The GLB is the runtime model; cinema.ts provides the screen players, occupancy, collisions and stair surface.

programmes.json holds two independent lists of direct HTTPS MP4/WebM video URLs. Each cycle (default 300 seconds) picks one pseudo-randomly using the shared UTC epoch. Both lists start empty until the owner chooses content. The internal defaults are matching neutral cards. The browser must be able to fetch the video with CORS and support its codec. Videos are muted by default and only load/play while a visitor is inside the cinema ground floor. Leaving or going to the rooftop releases the media; no video downloads, playback or programme requests happen while outside. The programme file is fetched on entry and falls back if missing or invalid. Refresh or re-enter to load programme edits. URLs to a webpage or YouTube page are not direct video files.

Cinema sound starts muted so it layers with existing music only when deliberately enabled. Use the on-screen Sound button for one screen at a time; volume defaults to 30%. Exiting the cinema or entering the rooftop resets it to muted. Browser autoplay and codecs may still require user interaction.
